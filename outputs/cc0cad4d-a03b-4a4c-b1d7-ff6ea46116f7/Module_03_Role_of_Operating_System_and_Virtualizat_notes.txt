# Role of Operating System and Virtualization

**Overview**
The operating system (OS) acts as a middleware between user applications and system hardware, providing a convenient interface for users to interact with the system. The OS manages computer hardware and resources, allowing multiple programs to run simultaneously and interacting with various I/O devices. The OS provides abstractions, such as process and virtual address space, to make it easy for users to use the system.

**Key Takeaways**
* The OS acts as an intermediary between user applications and system hardware, managing computer hardware and resources.
* The OS provides services, executes programs, and manages memory and I/O devices.
* Virtualization is a key concept in OS, providing abstractions such as process and virtual address space to make it easy for users to use the system.
* The OS provides a convenient interface for users to interact with the system, allowing multiple programs to run simultaneously.
* The OS manages the sharing of resources, such as CPU and memory, among multiple programs, providing an illusion of dedicated resources to each program.

**Important Terms and Definitions**
* **Operating System (OS)**: a middleware between user applications and system hardware that manages computer hardware and resources.
* **Virtualization**: the process of providing abstractions, such as process and virtual address space, to make it easy for users to use the system.
* **Process**: an abstraction provided by the OS, allowing user programs to run without worrying about the underlying CPU.
* **Virtual Address Space**: an abstraction provided by the OS, allowing each program to have its own private memory space without worrying about the physical addresses.
