# Introduction to CPU Virtualization

**Overview**
CPU virtualization is a technique that allows multiple virtual resources to be created from a single physical resource, such as a CPU. This is achieved by providing each running program with a virtualized environment, making it seem like it has its own dedicated CPU and memory. The goal of CPU virtualization is to provide efficient and secure resource sharing.

**Key Takeaways**
* CPU virtualization involves time sharing, where the CPU's time is divided among multiple processes, allowing them to run concurrently.
* Efficiency is a key design aspect of CPU virtualization, as adding virtualization mechanisms can introduce overhead.
* Security is also crucial, as it restricts processes from accessing or modifying resources they shouldn't, preventing system problems.

**Important Terms**
* Time sharing: a technique where resources are shared among multiple processes by dividing the available time among them.
* Multi-programming: a term used to describe the concurrent execution of multiple programs on a single CPU, achieved through time sharing.
