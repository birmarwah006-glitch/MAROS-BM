# Role of Operating System and Virtualization

**Overview**
The operating system (OS) acts as a middleware between user applications and system hardware, providing a convenient interface for users to interact with the system. The OS manages computer hardware resources such as CPU, memory, and disk, and enables multiple programs to run simultaneously through virtualization. This allows each program to feel like it has its own dedicated CPU and private memory, without worrying about other programs running in the background.

**Key Takeaways**
* The OS provides a layer of abstraction between user applications and system hardware, making it easy for users to interact with the system.
* The OS manages computer hardware resources such as CPU, memory, and disk, and allocates them to running programs.
* Virtualization is a key feature of OS, which provides abstractions such as process or thread for CPU and virtual address space for memory.
* The OS enables multiple programs to run simultaneously, creating an illusion that each program has its own dedicated CPU and private memory.
* The OS provides services such as executing programs, storing data, and interacting with I/O devices, while minimizing overhead and ensuring high performance.

**Important Terms**
* **Operating System (OS)**: a middleware between user applications and system hardware that manages computer hardware resources and provides a convenient interface for users.
* **Virtualization**: a technique used by OS to provide abstractions such as process or thread for CPU and virtual address space for memory, creating an illusion that each program has its own dedicated resources.
* **Process**: an abstraction provided by OS for CPU, which allows a program to run independently without worrying about the underlying CPU.
* **Virtual Address Space**: an abstraction provided by OS for memory, which gives each program its own private memory space, making it feel like it has its own dedicated memory.
